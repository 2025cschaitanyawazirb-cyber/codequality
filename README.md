# Automated Code Quality Checker

A tool that automatically analyzes Python code for style errors, bugs, and quality issues. It runs on every push to GitHub using GitHub Actions, following CI/CD principles.

## Technologies
- Python
- Git and GitHub
- GitHub Actions
- flake8 and pylint
